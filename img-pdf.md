# Документація (User Guide)


## Опис утиліти


`img-pdf` — це консольний скрипт для Linux (Manjaro, Ubuntu, Arch тощо), призначений для зручного та ефективного конвертування растрових зображень формату `JPG/JPEG` в один стиснутий документ `PDF`.


### Чому використано саме дві утиліти?


1. `img2pdf`: Миттєво упаковує оригінальні зображення в PDF-контейнер без перекодування. Прапорець --`rotation=off` захищає від збоїв при обробці нестандартних тегів орієнтації EXIF (наприклад, `Orientation=0`).

2. `Ghostscript` (`gs`): Бере зібраний PDF і виконує інтелектуальне стиснення з узгодженням роздільної здатності зображень (DPI), що дозволяє гнучко зменшити підсумковий розмір документа.


## Установка


### 1. Встановлення системних залежностей


Переконайся, що в системі встановлено `img2pdf` та `ghostscript`:

* Manjaro / Arch Linux:

```Bash
sudo pacman -S img2pdf ghostscript
```

* Ubuntu / Debian:

```Bash
sudo apt install img2pdf ghostscript
```


### 2. Розміщення скрипта


Зробіть файл виконуваним і перемістіть у системну директорію, щоб викликати його з будь-якого місця системи:

```Bash
chmod +x img-pdf
sudo mv img-pdf /usr/local/bin/
```


## Синописи та ключі запуска


```Bash
img-pdf [-q quality] [-o output.pdf] [файл1.jpg файл2.jpg ...]
```


### Доступні прапорці:


| Ключ  | Повна назва | Опис                                             | За замовчуванням |
| :---: | :---------- | :----------------------------------------------- | :--------------- |
| `-o`  | `--output`  | Шлях/назва вихідного `.pdf` файлу                | `output.pdf`     |
| `-q`  | `--quality` | Рівень якості та стиснення Ghostscript           | `ebook`          |
| `-a`  | `--author`  | Записує значення автора у метадані PDF (/Author) | `username`       |
| `-h`  | `--help`    | Вивести коротку інструкцію та завершити роботу   | —                |
| `-v`  | `--version` | Вивести версію скрипта                           | —                |



## Профілі якості (`-q` / `--quality`)


Ви можете обирати один із 4 системних профілів стиснення Ghostscript:

1. `screen` (~72 dpi):

    * Призначення: Максимальне стиснення, дуже малий розмір файлу.

    * Використання: Для відправки через обмежені ліміти (наприклад, форми з лімітом у 2 Мб), або коли важливий лише текст на сканах.

2. `ebook` (~150 dpi — За замовчуванням):

    * Призначення: Оптимальний баланс якості зображення та підсумкового розміру.

    * Використання: Для читання з моніторів, планшетів, надсилання поштою чи в месенджерах.

3. `printer` (~300 dpi):

    * Призначення: Висока якість з деталізацією.

    * Використання: Для подальшого роздруку документа на принтері.

4. `prepress`:

    * Призначення: Максимальне збереження деталей і точна кольоропередача.

    * Використання: Для професійної поліграфії (мінімальне стиснення).


## Приклади використання


1. Швидка обробка всіх `.jpg` у папці:
(Створить `output.pdf` із профілем `ebook`)

```Bash
img-pdf
```

2. Конвертувати всі зображення і задати власну назву:

```Bash
img-pdf -o passport_scans.pdf *.jpg
```

3. Максимальне стиснення для надсилання поштою (профіль `screen`):

```Bash
img-pdf -q screen -o low_size_doc.pdf *.jpg
```

4. Вибір конкретних файлів та чіткого порядку сторінок:

```Bash
img-pdf -o report.pdf cover.jpg page1.jpg page2.jpg appendix.jpg
```

5. Висока якість для друку (профіль `printer`):

```Bash
img-pdf -q printer -o print_ready.pdf *.jpg
```
